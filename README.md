# Auto Replies – first-time content

Static HTML/CSS for the Auto Replies first-time (empty state) content area: hero with animation, three setup steps, and the posts/stories section. No nav or header.

- `index.html`: the whole page. Styles are inline, and hover states plus @keyframes are in the <style> block in <head>. No JavaScript.
- `fonts/`: the Bitly Display woff2 files.
- `images/`: any image assets.
- Icons come from Google Material Icons / Material Symbols (CDN links in <head>).

Colors: primary #2a5bd7 (hover #0c3ebb), text #273144 / #151b26 / #3a4863, border #dbe0eb, page bg #f4f6fa, hero bg #96de94.
